# Chillax

Self-hosted unmodified font from Indian Type Foundry / Fontshare.
Official package: https://api.fontshare.com/v2/fonts/download/chillax
Official family page: https://www.fontshare.com/fonts/chillax
Retrieved: 2026-10-27.

`chillax-variable.woff2` is the official package's web variable font, with a weight axis from 200 to 700.
Use 500 for Hum body and labels and 600 for display, per Hallmark.
The complete unmodified ITF Free Font License from the download is in `LICENSE-Chillax.txt`.
`fontshare-package.css` is the original package CSS retained as provenance, not loaded by the site.

```css
@font-face {
  font-family: 'Chillax';
  src: url('/fonts/chillax-variable.woff2') format('woff2');
  font-weight: 200 700;
  font-style: normal;
  font-display: swap;
}
```
